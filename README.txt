UNDANGAN ANIMATED PREMIUM
===========================
Data masih dummy: Raka & Aisyah.

File:
- index.html
- style.css
- script.js

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html.
3. Untuk GitHub Pages, upload ketiga file ke repository.
4. Ganti nama, tanggal, acara, rekening, foto, dan musik sesuai kebutuhan.
5. Musik dapat ditambahkan dengan mengisi src pada <audio id="music">.

Catatan:
Foto hero menggunakan gambar dari Unsplash. Untuk penggunaan produksi, sebaiknya ganti dengan foto sendiri.
